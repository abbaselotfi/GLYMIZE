# R30-02-D1/D2 — Source projection and reference-lite implementation

Started: 2026-09-12; final verification continued 2026-09-13. Model recommendation: Astra Medium. Implements the bounded [D design](architecture/OFFLINE_REFERENCE_AUTHORITY_R30_02_D.md), not offline clinical authorization or a production release.

## Implemented boundary

- Type 2 source projection accepts exact `nfi_verified`; downstream master-match `verified` and engine/payer policy are unchanged. Malformed rows, other statuses, unavailable products, invalid/missing observation and source URLs are excluded with fixed-category counts. Missing license stays unknown; no fabricated current timestamp, active license or source URL. Shared validated full-market transport remains authoritative. Raw input remains available through that loader.
- `/offline/` is an exact standalone public route, not a clinical auth bypass. It has reference search, 30-row pagination, source identity/date/hash and explicit reference-only/unknown-state messages. No patient inputs, dose/ranking, claim promises, draft catalog or engine singleton calls. Search stays in component memory. External source links require user action and omit referrers.
- Build-time `offline-reference-projection.mjs` runs the existing market validator, verifies deployment SHA and emits only explicitly listed reference fields. No raw admin metadata, insurance policy, notifications, import history or author fields are projected. This narrows existing published content; it does not establish new redistribution rights or clinical approval.
- The opt-in/default-off `reference-lite` bundle contains home/offline documents, static resources and `offline-reference.json`; no raw admin catalog, raw market JSON/chunks or clinical-route documents. Other app-route chunks are excluded. Shared chunks remain because the root layout shares browser code; no claim of a separately isolated JavaScript distribution.
- A user-triggered download registers the service worker and waits for installation and an explicit reference-lite version response. Incomplete installation is not ready. Hash verification/atomic activation remain; activation removes only this scope's legacy PWA/experimental cache namespaces and retains at most one previous reference-lite bundle. Other application caches and catalog drafts are untouched. Clearing/evicting browser storage can remove offline availability.
